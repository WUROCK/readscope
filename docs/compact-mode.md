# 简洁模式与透明度

## 日常使用

- 默认 420×160 的双行摘要，与完整面板共享标题栏和宽度，切换仅改变高度。
- 标题栏“在读 / 统计 / 文献”直接切换摘要，无需先展开；展开后保留当前页面。
- 在读显示优先级最高、尚未读完的一本书，保留封面、作者、标签及进度。没有自定义顺序时按最近阅读显示。
- 统计显示本周与本月累计；今日时长与目标进度保留在完整在读页。
- 文献显示标题，长标题悬停查看全文。
- 点击摘要或展开按钮进入完整面板；点击收起或在没有弹窗时按 Esc 返回摘要。
- 点击设置会先展开窗口再打开设置；品牌及标题栏空白区域可拖动。

## 书籍排序

完整在读页点击“排序”，拖动书籍或使用上下按钮调整，顺序自动保存，最后点击“完成排序”。排序同时适用于微信读书和手动书籍，简洁摘要同步采用已保存的顺序。保存失败会显示错误并保留上次成功保存的顺序。

排序模式展示完整书单并暂停筛选与横滑切页，避免拖动与翻页冲突。新书加入已排序书籍的尾部；“恢复最近阅读”清除自定义顺序。

顺序存入数据目录 settings.json 的 readingOrder 字段，兼容旧设置，与浏览器地址和应用启动端口无关。复制数据目录即可带走此偏好。

## 透明度及窗口切换

设置 → 窗口外观 → 窗口不透明度，范围 45%–100%，默认 90%，调整即时生效并自动保存。文字也会随窗口变淡。托盘菜单可切换模式或重置窗口外观。

窗口形态、透明度、位置和尺寸保存在 window-state.json（版本 8，兼容版本 6/7）。简洁模式通过最小/最大高度限制为 160，不再反复切换原生可调整大小样式。页面保持 #16181b 深色；Windows 原生窗口在创建时使用透明绘制底层，避免动态扩展的未绘制区域先被系统填成白色。窗口可调整大小样式自创建起保持不变。展开/收起用 260 毫秒平滑插值改变原生窗口高度，标题栏保持对齐，导航随高度展开，内容在 60 毫秒后轻微上移并淡入。仅内容参与淡入，新增区域的页面深色背景会随绘制出现。快速反向点击从当前高度继续，不跳回旧尺寸；系统“减少动态效果”开启时直接切换。动画中间尺寸不会写入偏好，退出时保存完整端点。

窗口变化仅在恢复或切换时限制在工作区，拖动过程不纠正尺寸。Windows 缩放产生的外框像素不会反馈到内容宽高；透明绘制层的宽高舍入校准会被复用，屏幕边缘的位置调整保留物理像素对齐关系，写入合并延迟为 300 毫秒，退出前立即保存。

## 版本与验证

Git 分支 feature/compact-widget；初始基线 88ee33b，标签 baseline-before-compact-mode。

当前通过类型检查、生产构建、17 项窗口逻辑检查、2 项日志检查及 30 项真实 Electron 界面检查。窗口逻辑覆盖高度单调变化、快速反向点击、DPI 缩放下多轮折展、退出落盘、工作区边缘与减少动态效果。npm run test:ui 结果保存在 artifacts/reference-layout-qa/summary.json。

界面检查覆盖摘要直接切页、400px 最小宽度、书籍上下移动和拖放事件、顺序保存及重载恢复、12 轮真实按钮折展、30 轮快速窗口切换，以及模式切换中的页面绘制。最新运行采集 339 帧，未检出白色页面帧；该采集覆盖渲染页面，不能直接观测 Windows 桌面合成器的瞬时画面。

验证使用隔离测试数据与隐藏窗口；日志直接写入文件，避免输出管道关闭触发 EPIPE。验收截图见 `docs/screenshots/06`–`08`（简洁横条三页，演示数据）。

更新后从托盘退出原应用，再运行 F 盘的启动阅界.cmd。切换源码版本后需重新构建界面。

## 实际桌面白带回归

页面截图无法覆盖 Windows 合成的临时灰白横带。现增加 npm run test:desktop:visible，使用独立测试数据、可见窗口及不透明的专属背景板，录制真实桌面画面。背景板上的两种颜色标记用于拒绝被其他窗口遮挡的录屏。此项需要 Windows 与 ffmpeg（PATH 中可用，或设置 FFMPEG_PATH）。

本机 150% 缩放下，8 轮折展覆盖 45%、90%、100% 不透明度：旧的不透明绘制底层在 719 帧中检出 18 帧横带；透明绘制底层在 719 帧中未检出，且所有帧均通过背景板标记检查。手动拖动右边缘也验证了 420→400 的宽度调整。结果仅代表这组本机录屏。

复查旧底层可设置 READSCOPE_FLASH_VARIANT=baseline；默认测试 fixed。录屏、横带检测计数及示例帧编号保存在 artifacts/desktop-flash-qa 对应目录。原始动画、透明度和窗口尺寸偏好均保留。
