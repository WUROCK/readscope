# 界面与交互修复 · 2026-10-29

> 后续已加入默认简洁横条与可调不透明度，当前使用方式和窗口状态以 [简洁模式与透明度](compact-mode.md) 为准。以下保留完整面板的前期修复记录。

> 2026-11-01：文献来源升级为优先检索正式出版记录，并加入旧记录补查和已核验备用池，见 [文献出处与补查](publication-sources.md)。

## 拖动与点击

- 旧标题栏的每次指针移动都会经 IPC 调用窗口定位，再将宽高恢复为拖动开始时的值；窗口自身的 resize 回调又会强制 2:3 比例。这些尺寸调整在 Windows 缩放、跨屏或拖边缘时可能互相争抢。
- 标题栏改用 Electron 原生拖动区域，移除自定义移动 IPC、固定比例和 resize 内的尺寸纠偏。按钮、导航和弹窗排除拖动。
- 窗口默认 420×630，宽高可分别调整；恢复时按窗口所在显示器的工作区约束，避免窗口移到屏幕外。
- 内容区不再于按下时立即捕获指针。普通按钮点击直接传给控件；确认横向手势后才开始切页，纵向手势保留滚动。
- 修正横滑后紧接着点击按钮被吞掉的问题；第二指按下、指针捕获丢失以及鼠标在窗口外松开后结束旧手势。
- 书籍页数使用完整数值校验；320.5、2.5 等小数会显示错误，不再静默截断。

## 字体与布局

- 炭灰背景 `#16181b`、柔和暖黄重点色 `#d8bb80`；移除网格、扫描线、光晕和多余描边。
- 正文 13px，书名及区块标题 14px，文献标题 15px，辅助说明 11–12px；减少粗体和重复的强调色。
- 标题栏第一排显示品牌与窗口控制，第二排显示导航；窗口按钮 28×28px，品牌与空白区域均可拖动。
- “添加书籍”位于在读标题旁；精简重复打卡文字，每本书默认显示两个标签。
- 文献只保留一个主要的“换一篇”入口；统计图标注实际年份。
- 内容独立滚动，弹窗正文滚动，底部保存/确认按钮保持可见。
