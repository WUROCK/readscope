# 阅界 · 石墨科技黄三页设计说明（v5）

> 本文保留旧版设计记录。当前的字体、布局、窗口拖动与缩放行为以 [界面与交互修复说明](interface-fixes.md) 和实际界面为准。

## 目标

420×630（竖版 2:3）的桌面小窗，可左右拖边缘等比缩放到 400–600 宽，石墨黑玻璃质感、无系统透明/Acrylic/阴影（避免窗口外灰层）。风格参考紧凑型待办应用（顶部条 + quick-add 输入条 + 扁平分隔线列表），颜色按用户要求改为**电光黄科技感**。三页只回答三个问题：

1. **在读**：最近在读什么？今天是否达标/打卡？这些书是什么标签？
2. **统计**：今年/本月读了多少、读完多少？
3. **每日文献**：今天读哪篇？

## 窗口

- Electron：无边框、默认 420×630（竖版 2:3），可左右拖边缘等比缩放（400–600 宽），不透明石墨底 `#07090c`、系统圆角、可拖拽；不使用 `transparent`、`backgroundMaterial: acrylic` 或窗口阴影。标题栏拖动只移动，尺寸锁定；拖边缘时高度按 2:3 跟随。
- `html/body/#root` 透明；内层 `.widget` 使用石墨黑近不透明玻璃 `rgba(14,17,22,.94)`；1px 黄描边 + 极淡科技网格/扫描线，不再使用厚重卡片或大光晕。
- 页面内容按 `.page` 独立滚动；顶部 38px 玻璃标题条固定。
- 拖拽由 TitleBar 的 pointer 事件 + IPC `startDrag/dragMove/dragEnd` 完成，不依赖 `-webkit-app-region`；页面默认 `user-select: none`，输入框恢复可选，避免拖动产生灰色选区。

## 调色

```
--bg-0: #07090c      --bg-1: #11151b
--glass: rgba(14,17,22,.94)
--glass-soft: rgba(255,214,10,.05)
--line: rgba(245,197,24,.14)
--text: #f6f5ee      --muted: #9b9a8d
--accent: #f5c518    --accent-2: #ffd60a
--success: #c9f05a   --danger: #ff6b6b
```

字体：`"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif`。数字 600 weight；小标签 9–10px、letter-spacing .08em。黄色只用于 active tab、进度条、图表/主按钮/链接，其余为石墨/奶油白。

## 顶部条

- 38px 圆角玻璃条：左侧书籍图标 + **阅界**；中间紧凑胶囊导航（在读 / 统计 / 每日文献，高 28px）；右侧同步圆点、设置、置顶、最小化、关闭小图标。
- 使用 `-webkit-app-region: drag`，按钮区 no-drag；保持 380–520px 宽自适应。

## 页面 1 · 在读

- 顶部两行 slim 状态：问候/日期 + 打卡 pill；下一行 2.5px 目标条 + `35 / 45 分钟` + `距目标还差 10 分钟`。无卡片背景。
- 42px quick-add 条：`＋ 添加在读的书，按回车创建`；点击或回车打开加书弹窗（标签自动生成）。
- `在读 N 本` 扁平分隔线列表：小封面 + 书名 + 来源 badge（仅手动书标"手动"）+ 作者 + 1–3 个小标签 + 2.5px 进度条 + 百分比 + 累计时长或页数；手动行右侧 `更新`。默认 4 本 + `查看全部 N 本`。
- 列表下方聚合标签 chips（可点击筛选）。
- 普通状态没有 footer；仅在同步失败时显示一行 inline error + 重试。

## 页面 2 · 统计

- 无大卡片。顶部大号 `今年累计阅读 47.8 小时`，下方一行 `今年读过 14 本 · 已读完 6 本 · 读了 75 天`。
- 本月三列（竖分隔线）：`本月阅读 3.5 小时` / `本月读过 5 本` / `本月阅读天数 12 天`。
- 12 个月无边框柱图，当前月用 accent；下方 `本周 4 天 · 日均 30 分钟` 与 `本月读完 X 本`。

## 页面 3 · 每日文献

- 页面标题 `每日文献` + 日期 + `换一篇`。
- 仅一块轻量半透明 panel：类型 / 来源 / 日期、标题、`期刊/会议 · 年份`、约 50 字摘要、最多 3 个标签、`阅读全文` + `换一篇`、CSV 去重提示。
- 下方最多 3 条最近的扁平列表；底部 CSV 路径与数量 + 打开文件夹。
- 不再有科研文献管理页；论文 API 保留但 UI 不出现。

## 弹窗

- 设置：Key（掩码/清除/测试连接）、45 分钟目标、30 分钟打卡、来源（论文默认 / 自动 / 公众号 / 精选）、研究关键词。
- 添加/编辑书籍：书名、作者、总页数、当前页、领域；标签由服务端自动分析；数值占位用"如 320""如 0"。
- 深色石墨扁平玻璃；错误内联显示；删除使用自定义确认。

## 交互

- 顶部标签点击、键盘 ←/→、鼠标/触控横滑切页。
- 打卡达标自动写入；窗口隐藏时 Electron 每 10 分钟轻量检查。
- 外部链接优先 Chrome，其次系统默认浏览器。
- 无外部字体/图片依赖；图标全部内联 SVG。

## 验收

- 420×630 首屏：顶部玻璃条、目标行、quick-add、4 本书 + 标签云；无底部导航。
- 统计页 12 根柱子、当前月高亮；数字来自 `overview.stats`（年/月读过/读完/天数）。
- 添加书籍：320 页 / 48 页 → 15%，出现在合并列表，标签自动出现；编辑/删除正常。
- 阅读全文：Chrome 打开新标签页；同步不再出现频繁超时。
- 无横向滚动条，无 research 页面入口。
